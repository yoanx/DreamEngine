# DreamEngine Beta v0.3.0-beta.2

第二个公开 Beta，修复插件升级后同名效果预览失联和效果数量膨胀的问题。

## 修复

- 插件预览身份改为「插件 + 效果显示名」，插件升级不再要求重新渲染
- 插件更新导致 `matchName` 变化时，同名效果继续复用原预览
- 旧预览索引会在首次读取时补写稳定预览键，避免升级 DreamEngine 后旧预览失联
- 当前 AE 已不存在的第三方效果不再计入正常效果数量，单独显示为历史预览
- Hub 效果库、AE 面板、批量渲染选择与取消渲染统一使用同一稳定预览身份
- 同名效果重新渲染时按稳定键替换旧索引，不产生新旧两条记录

## 安装

1. 保存工程并关闭 After Effects。
2. 运行 `DreamEngine-Hub-Setup-0.3.0.exe`。
3. 启动 AE，打开 `窗口 > 扩展 > DreamEngine`。

安装与升级只替换程序文件，不覆盖用户预设、分类、收藏或已生成预览。

安装包大小：282,741,126 字节（269.64 MB）；SHA256：`E2C6C659B2C7B5B39451C3A0F483AECD3633899CDAEDA40DB425D24ECB375990`。

安装包未签名，SmartScreen 可能提示未知发布者。

# DreamEngine Beta v0.3.0-beta.2

The second public beta fixes lost previews and inflated effect counts after plugin upgrades.

## Fixed

- Plugin preview identity now uses plug-in plus effect display name, so a plugin upgrade no longer requires a rerender
- If an update changes `matchName`, the same named effect continues to use its existing preview
- Existing preview indexes are migrated with a stable preview key on first read
- Third-party effects no longer installed in the current AE are excluded from the active effect count and reported separately as historical previews
- Hub, the AE panel, render selection, and preview clearing all use the same stable identity
- Rerendering a same-name effect replaces the old index entry instead of creating duplicate old/new records

## Installation

1. Save your project and close After Effects.
2. Run `DreamEngine-Hub-Setup-0.3.0.exe`.
3. Start AE and open `Window > Extensions > DreamEngine`.

Installing or upgrading replaces program files only; user presets, categories, favorites, and generated previews are preserved.

Installer size: 282,741,126 bytes (269.64 MB); SHA256: `E2C6C659B2C7B5B39451C3A0F483AECD3633899CDAEDA40DB425D24ECB375990`.

The installer is unsigned, so SmartScreen may show an unknown-publisher warning.
