# DreamEngine Beta v0.3.0-beta.1

DreamEngine 0.3.0 的第一个公开 Beta，加入统一的预览渲染流程、人工调参、效果 WebP 动画预览和多版本 AE 渲染模板，并继续完善面板与素材工作流。

## 新增

- Hub 新增五步预览渲染流程，统一处理预设与插件效果的选集、配置、渲染和结果统计
- 新增效果人工调参：获取参数树、调整参数、保存覆盖值并在下一次渲染时复用
- 效果预览支持动画 WebP，只加载一个文件即可悬停播放，并正确区分动态与静态效果
- 新增 AE 崩溃修复看守、专用渲染实例、断点继续、失败重试与崩溃黑名单
- 新增更新检查、自定义效果预览背景和效果预览包导入导出
- 面板同步 Hub 的预设与分类，移除面板内直接渲染入口，避免与宿主 AE 争用
- 曲线与素材页补齐多点编辑、子目录浏览、音频波形和视图持久化
- 同一 AE 默认预设在跨版本同名时复用已有预览，避免切换 AE 版本后错误显示为待渲染
- Sapphire Transitions 自动使用前景 / 背景两层输入并开启 Auto Trans，可生成完整转场动画

## 修复

- 按 AE 主版本生成并复用对应的 PNG 渲染模板，避免 AE 2023 工程在 AE 2021 中启动
- 修复文字类预设预览裁切、关键帧范围不足与静态误判
- 修复预览帧遗留、类型转换失败、同名索引覆盖和渲染任务并发状态
- 修复多 AE 版本安装路径检测、素材目录回退与面板卡片布局

## 安装

1. 保存工程并关闭 After Effects。
2. 运行 `DreamEngine-Hub-Setup-0.3.0.exe`。
3. 启动 AE，打开 `窗口 > 扩展 > DreamEngine`。

安装与升级只替换程序文件，不覆盖用户预设、分类、收藏或已生成预览。

安装包大小：282,739,213 字节（269.64 MB）；SHA256：`050A17AFE0E10BD64C96E310FAF8F4C2FDDC4F9CD5D00AC4509E25809E5912CC`。

安装包未签名，SmartScreen 可能提示未知发布者。

# DreamEngine Beta v0.3.0-beta.1

The first public beta of DreamEngine 0.3.0 adds a unified preview-render workflow, manual effect tuning, animated WebP previews, multi-version After Effects templates, and further panel and media workflow refinements.

## Added

- A five-step preview-render flow for presets and plug-in effects, covering selection, configuration, rendering, and result summaries
- Manual effect tuning with parameter acquisition, value editing, persisted overrides, and reuse in later renders
- Animated WebP effect previews with one-file hover playback and reliable static/animated detection
- AE crash-guard handling, dedicated render instances, resume support, retries, and crash blacklisting
- Update checks, custom effect-preview backgrounds, and effect-preview package import/export
- Panel synchronization with Hub presets and categories, with panel-side rendering removed to avoid competing with the host AE process
- Expanded curve editing, media subfolder browsing, audio waveforms, and persisted view state
- Same-name default AE presets now reuse existing previews across AE versions
- Sapphire Transitions now use foreground/background inputs with Auto Trans enabled to render the complete transition

## Fixed

- PNG render templates are generated and reused per AE major version, preventing AE 2023 projects from opening in AE 2021
- Fixed text-preset clipping, short keyframe ranges, and static-preview misclassification
- Fixed stale preview frames, conversion failures, same-name index collisions, and render-job concurrency state
- Fixed multi-version AE discovery, media-folder fallback, and panel card layout

## Installation

1. Save your project and close After Effects.
2. Run `DreamEngine-Hub-Setup-0.3.0.exe`.
3. Start AE and open `Window > Extensions > DreamEngine`.

Installing or upgrading replaces program files only; user presets, categories, favorites, and generated previews are preserved.

Installer size: 282,739,213 bytes (269.64 MB); SHA256: `050A17AFE0E10BD64C96E310FAF8F4C2FDDC4F9CD5D00AC4509E25809E5912CC`.

The installer is unsigned, so SmartScreen may show an unknown-publisher warning.
